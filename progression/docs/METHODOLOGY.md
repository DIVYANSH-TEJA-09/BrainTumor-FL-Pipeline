# Methodology

## I. Data Pipeline

### Dataset
- **MU-Glioma-Post** from TCIA (The Cancer Imaging Archive)
- 203 patients, 791 patient-timepoint MRI studies
- Post-operative longitudinal imaging (multiple scans per patient over months/years)
- Modalities: T1, T1CE, T2, FLAIR with expert tumor segmentation masks

### Volume Extraction
Real tumor volumes extracted from NIfTI segmentation masks using:
```python
tumor_mask = (segmentation_data > 0)  # binarize labels
tumor_voxels = np.sum(tumor_mask)
volume_mm3 = tumor_voxels * voxel_volume  # from affine matrix
```

### Grade Stratification
Patients separated by WHO tumor grade (from clinical metadata):
- **HGG (High-Grade Glioma, Grade III-IV):** 89 patients — aggressive, faster growth
- **LGG (Low-Grade Glioma, Grade I-II):** 22 patients — slow, more predictable growth

Biological justification: Different cellular biology demands separate modeling.

### Time Spacing
Actual scan dates from clinical records (`day_from_diagnosis_imputed`), not hardcoded assumptions. Inter-scan intervals vary from weeks to months per patient.

## II. Mathematical Model: Per-Patient Logistic Growth

### Formula
```
V(t) = K / (1 + ((K - V₀) / V₀) × e^(-r × t))
```

### Parameters
| Parameter | Meaning | Typical HGG | Typical LGG |
|-----------|---------|-------------|-------------|
| V₀ | Initial volume at first scan | 50,000–200,000 mm³ | 20,000–80,000 mm³ |
| K | Carrying capacity (max size) | ~1,900,000 mm³ | ~2,500,000 mm³ |
| r | Intrinsic growth rate (day⁻¹) | 0.073 | 0.062 |

### Fitting
- `scipy.optimize.curve_fit` per patient
- Evaluation: R², MAE, RMSE with temporal holdout (70% train, 30% test)

### What We Tried and Failed
1. **Covariate-Augmented Logistic** — Predict K, r from clinical features (ElasticNet). Result: Grade median baseline outperformed it (R² 0.166 vs 0.063). Weak signal-to-noise in covariates.
2. **Treatment-Forced ODE v1** — Binary treatment indicators. Result: +3.8% worse RMSE.
3. **Treatment-Forced ODE v2** — Separate chemo/radiation with decay. Result: +410% worse RMSE. Catastrophic failure — insufficient temporal data to constrain ODE parameters.

### Conclusion
Per-patient logistic fit is the best mathematical approach. Grade-stratified median parameters provide a stable baseline.

## III. LSTM Hybrid: Residual Correction

### Key Insight
Instead of training an LSTM to predict absolute volumes (hard), train it to predict **where the logistic baseline fails** (easier):

```
V_hybrid(t) = V_logistic(t) + LSTM_correction(t)
```

### Architecture
```
Input: 3 previous residuals (1D sequence)
  → LSTM(hidden_size=32, 1 layer)
  → MultiheadAttention(4 heads, context-aware weighting)
  → FC(32→64→ReLU→32→ReLU→1)
Output: predicted next residual
```
Total parameters: 12,929

### Training
- **HGG model:** 58 epochs, best test MSE = 0.513 (early stopped, patience=15)
- **LGG model:** 20 epochs, best test MSE = 0.869
- Optimizer: Adam (lr=0.001)
- Loss: MSE on normalized residuals
- Temporal split: 70% early timepoints (train), 30% late (test)

### Limitation
LSTM requires lookback of 3 residuals before making corrections. For patients with ≤3 timepoints, `V_hybrid = V_logistic` (no correction applied).

## IV. 3D Visualization Strategy

### Volume-Scaled Masks
For 3D rendering, predicted tumor masks are generated by scaling the actual input mask:
```python
predicted_mask = actual_mask × (predicted_volume / actual_volume)
```

**Advantages:** Preserves anatomical shape and location; computationally fast.
**Limitation:** Does not predict spatial growth direction — assumes uniform expansion/contraction. This is acknowledged in the dashboard.

### Dashboard Workflow
```
1. Select patient and input scan (Timepoint N)
2. App predicts volume for Timepoint N+1 using both methods
3. Ground truth (actual scan N+1) shown for validation
4. Growth curve, residuals, and error comparison displayed
5. Method explanation shows formula, parameters, and architecture
```

---

## V. Evaluation Protocol

- **Temporal cross-validation:** Models trained on early timepoints, tested on later ones (no data leakage)
- **Grade-stratified metrics:** HGG and LGG reported separately
- **Metrics:** MAE, RMSE, R² — all computed on held-out test timepoints
- **Honest assessment:** R² ~0.1 at population level (high individual heterogeneity), R² ~0.6 at per-patient level
