01 — Introduction

Why does this
problem matter?

Brain tumors require highly accurate detection, segmentation, and continuous monitoring to support timely clinical decisions. Traditional manual MRI analysis is slow, subjective, and limited by human fatigue. Existing AI systems perform isolated tasks — basic classification or 2D segmentation — without understanding tumor evolution over time.

Problem Statement: A Federated Multimodal AI Framework with QPSO for Brain Tumor Classification, 3D Glioma Segmentation, and Tumor Progression Analysis — enabling precision neurodiagnostics without compromising patient data privacy.

01

3D Volumetric Understanding

4-channel MRI volumes (T1, T1ce, T2, FLAIR) processed by a 3D Attention U-Net for full spatial context.

03

Longitudinal Forecasting

Tumor volume trajectories fitted with biologically-aware growth models and corrected via LSTM networks.

04

Clinical Decision Support

Outputs include classification reports, 3D masks, uncertainty estimates, and 6-month volume projections.

02 — Abstract

What we built

This project proposes a multimodal AI framework for brain tumor diagnosis and monitoring. The system integrates 3D Attention U-Net based segmentation, federated tumor classification, and longitudinal tumor progression forecasting.

Federated learning enables multiple hospitals to collaboratively train models while keeping patient data private. A Quantum Particle Swarm Optimization (QPSO) based aggregation strategy improves federated learning convergence and inter-client fairness.

The system predicts future tumor growth from longitudinal MRI scans using mathematical models and LSTM networks. The integrated pipeline provides segmentation maps, tumor classification, growth prediction, and clinical risk assessment.

Key algorithmic

def aggregate_qpso(self, client_weights, client_val_accs):
    """
    QPSO Aggregation: Update pbest/gbest,
    compute mbest, apply quantum position update.
    """
    # Step 1: Update personal best and global best
    for client_id, weights in client_weights.items():
        val_acc = client_val_accs[client_id]
        if val_acc > self.personal_best_scores[client_id]:
            self.personal_best[client_id] = weights
            self.personal_best_scores[client_id] = val_acc
        if val_acc > self.global_best_score:
            self.global_best = weights
            self.global_best_score = val_acc

    # Step 2: Compute mean best (element-wise mean of all pbests)
    self.mean_best = compute_mean_state_dict(
        [self.personal_best[c_id] for c_id in self.clients]
    )

    # Step 3: Quantum position update for each parameter
    for param_name in self.global_model.state_dict():
        φ = random.uniform(0, 1)   # per-client attraction weight
        u = random.uniform(0.3, 1.0) # quantum randomness

        # Attraction point: weighted combo of pbest and gbest
        p = φ * mean_best[param_name] + (1 - φ) * gbest[param_name]

        # Quantum update: stochastic jump with bounded magnitude
        perturbation = β * abs(mean_best[param_name] - gbest[param_name]) * ln(1/u)
        perturbation = clip(perturbation, -0.1, 0.1)
        new_position = p + random.choice([-1, 1]) * perturbation
        w_new[param_name] = new_position

    return w_new
def segment_patient(model, patient_image_path, device):
    """Segment one patient's 3D MRI volume via sliding window."""
    # Load and preprocess 4-channel NIfTI volume
    sample = train_transforms({
        "image": patient_image_path,
        "label": patient_image_path
    })
    image = sample["image"].unsqueeze(0).to(device)  # (1, 4, H, W, D)

    model.eval()
    with torch.no_grad():
        # Sliding window inference: 96³ patches, 50% overlap
        outputs = sliding_window_inference(
            inputs=image,
            roi_size=(96, 96, 96),
            sw_batch_size=4,
            predictor=model,
            overlap=0.5
        )

    # Apply sigmoid + threshold → binary masks
    predictions = (outputs.sigmoid() > 0.5).float()
    return predictions  # (1, 3, H, W, D) — [WT, TC, ET]

def train_hybrid_lstm(model, train_loader, val_loader, device, epochs=50):
    """Train Attention-LSTM on logistic residual sequences."""
    optimizer = torch.optim.Adam(model.parameters(), lr=0.001)
    criterion = nn.MSELoss()

    for epoch in range(epochs):
        model.train()
        train_loss = 0.0
        for x_batch, y_batch in train_loader:
            x_batch = x_batch.to(device)
            y_batch = y_batch.to(device)

            optimizer.zero_grad()
            y_pred = model(x_batch)          # V_hybrid = V_logistic + LSTM_correction
            loss = criterion(y_pred, y_batch)
            loss.backward()
            optimizer.step()
            train_loss += loss.item()

        train_loss /= len(train_loader)

        # Validation
        model.eval()
        val_loss = 0.0
        with torch.no_grad():
            for x_batch, y_batch in val_loader:
                y_pred = model(x_batch.to(device))
                val_loss += criterion(y_pred, y_batch.to(device)).item()
        val_loss /= len(val_loader)

        if epoch % 10 == 0:
            print(f"Epoch {epoch}: Train={train_loss:.6f}, Val={val_loss:.6f}")

Key Takeaways

Global accuracy hides inequity — per-client fairness metrics are essential in clinical federated learning.

Biologically-aware growth models with LSTM residual correction outperform pure data-driven approaches.
